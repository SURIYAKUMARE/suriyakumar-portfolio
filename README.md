An Awwwards-caliber, scroll-driven personal portfolio website for **Suriyakumar E** (*Data Analytics | AI & ML Engineering Student* at Rathinam Technical Campus, Coimbatore). Engineered using the **SpaceEdu 4-phase cinematic reveal architecture** with GSAP ScrollTrigger pinning and zoom transitions, elegant serif typography, and deep-space starfield ambiance.

---

## 🌟 Key Features

- **SpaceEdu 4-Phase Cinematic Project Showcase**:
  - **Phase 1 (Hero State)**: Centered eyebrow, massive serif title in Playfair Display, cyan accent line, pill "VIEW PROJECT" button, docked left/right circular prev/next thumbnails, and planet-style rising mockup.
  - **Phase 2 (Split Reveal)**: Project visual scales and glides to one side while the opposite text drawer slides in with descriptions, tech tags, and the circular "▶" case study trigger.
  - **Phase 3 (Full-Bleed Zoom Transition)**: GSAP ScrollTrigger pins the section and scales the visual dramatically until it fills the viewport, revealing an anchored bottom-right technical detail callout box.
  - **Phase 4 (Seamless Hand-off)**: Crossfade and scale into the next project's Phase 1 hero panel.
- **The 5 Core Showcased Projects**:
  1. *NSG Live Location Tracking* (Hardware-based GPS telemetry & asset tracking)
  2. *Cotsify.shop* (Modern e-commerce web application)
  3. *Student Performance Analysis* (Data analytics, statistical modeling & Power BI)
  4. *Hostel Complaint Management System* (Campus issue triage & role-based escalation)
  5. *Smart Attendance System using Face Recognition* (Computer vision & facial embeddings)
- **Deep Space Interstellar Theme**: Dark navy palette (`#0a0e17`), electric cyan accents (`#00f0ff`), canvas starfield particles, and tactile noise texture overlay.
- **Additional Sections**:
  - **About Me**: 3D tilt-on-mousemove portrait card, bio, and interactive skill bars (*SQL, Pandas, NumPy, Power BI, Python, OpenCV, Vector Databases, C++, Java*).
  - **Academic Foundation**: Vertical illuminated timeline for Rathinam Technical Campus and Harvard Hi-Tech Matric HSS.
  - **Certifications & Honours**: Interactive badge grid featuring Google Data Analytics, Microsoft AI, Advanced RAG, and the **YUDHISTRA 2K26 Award** gold trophy card.
  - **Contact Experience**: Floating label inputs, morphing checkmark micro-animation with confetti burst, copyable email & phone pills, and direct LinkedIn/GitHub links.
  - **Admin Studio (`/admin`)**: Supabase auth-gated dashboard to manage projects and bio live.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation & Scrolling**: [GSAP ScrollTrigger](https://greensock.com/), [Framer Motion](https://www.framer.com/motion/), [Lenis](https://github.com/darkroomengineering/lenis)
- **Backend & Auth**: [Supabase](https://supabase.com/) (with built-in local persistence fallback)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/SURIYAKUMARE/suriyakumar-portfolio.git
cd suriyakumar-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### 4. Build for production
```bash
npm run build
npm run start
```
